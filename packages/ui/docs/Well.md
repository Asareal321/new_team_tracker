# Well

A recessed tray holding a column of task rows.

The well is routed *into* the board rather than sitting on it, so it has a sunk surface and no edge beneath — the inverse of a piece.

```jsx
<Well label="Today">
  <TaskRow title="Fix the rail contrast" emphasis="high" />
  <TaskRow title="Move coins to the server clock" emphasis="due" />
</Well>
```
