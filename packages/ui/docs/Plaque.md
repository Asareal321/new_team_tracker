# Plaque

A carved nameplate — the heaviest piece in the system, set in the display face.

Plaques name a place: the board, a page, a zone. They never contain data and never wrap to two lines. This is the only centred element in Beech & Baize.

Never set a plaque in the body face. The display/body split is load-bearing — a plaque in Inter is just a brown box.
