# Button

A painted wooden piece you can press. `primary` is the only accent-coloured control on a screen.

Carries the interaction physics: lifts 1px on hover, presses 2px down on `:active`, edge shrinking to 1px. Colour never changes on interaction — only geometry.

There is deliberately no ghost or tertiary variant. A screen needing a third level of action has too many actions; demote one to a text link.
